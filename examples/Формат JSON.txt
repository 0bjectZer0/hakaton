Формат данных для двухнедельного цикла

Поместите пять файлов UTF-8 в одну папку. Идентификаторы — строки, уникальные
в пределах одного справочника. Пример в этой папке искусственный.

groups.json — список групп. У группы обязательны id и size (число студентов).
teachers.json — список преподавателей. У преподавателя обязательное поле id.
rooms.json — список аудиторий. Поле capacity задаёт число мест. Планировщик
складывает численность всех групп общего занятия. Отсутствующее значение
capacity означает, что вместимость неизвестна. Поле features — список
возможностей аудитории, например ["компьютеры", "проектор"].
subjects.json — список дисциплин. Поле features перечисляет требуемые
возможности. Все перечисленные возможности должны быть у выбранной аудитории.

lessons.json содержит параметры календаря и список lessons. В days укажите
число учебных дней недели (1–7), в daily_limit — предельное число пар за день
у группы и у преподавателя. bells — именованные сетки звонков. Каждая пара
задана двумя строками "ЧЧ:ММ". Начало следующей пары может совпадать с концом
предыдущей. При нескольких сетках занятость определяется в минутах.

Одна строка lessons — одно обязательное занятие в повторяющемся цикле.
Укажите его id, дисциплину subject, преподавателя teacher, список groups
и список разрешённых аудиторий rooms. Общую лекцию опишите одной строкой,
включив все группы потока. Пустой список rooms допустим как описание
нехватки ресурсов: такое занятие попадёт в список требующих назначения.
Несколько занятий по одному предмету задаются разными id.

Необязательные поля строки занятия

• weeks — [0] для числителя, [1] для знаменателя, [0, 1] для обеих недель.
  По умолчанию занятие проходит обе недели. Занятие на обеих неделях получает
  один и тот же день, номер пары и аудиторию.
• duration — число последовательных пар, по умолчанию 1. Лабораторная с
  duration = 2 занимает два места в дневной нагрузке и закрепляет аудиторию
  с начала первой пары до конца второй, включая перемену. Все участники
  и аудитория должны быть доступны на каждой паре блока.
• bell — имя сетки из bells, по умолчанию "main".
• available — список разрешённых окон.

Окно доступности в available — тройка [неделя, день, пара]. Все индексы
начинаются с нуля. Например, [1, 0, 2] — третья пара понедельника по
знаменателю. available можно задать для преподавателя, аудитории и занятия.
При планировании применяются все три ограничения. Отсутствие поля открывает
всю сетку, пустой список закрывает все окна. Для блока duration = 2 внесите
в список обе соседние пары. Окна описывают повторяющийся цикл.

keys в записи аудитории задаёт физические части помещения. Например,
две аудитории с keys ["A"] и ["B"] можно использовать одновременно.
Зал с keys ["A", "B"] при назначении занимает обе. Если keys пропущено,
физический идентификатор равен id аудитории. Для дистанционного занятия
можно завести отдельную аудиторию с virtual = true: это снимает резервирование
физического помещения, сохраняя занятость преподавателя и студентов.

Для сравнения весов и альтернатив сохраните неизменной всю папку исходных
файлов. Оценка относится именно к указанным занятиям и ограничениям.
