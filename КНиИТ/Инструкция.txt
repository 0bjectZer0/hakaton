КНиИТ СГУ. Программа для Python 3.10 и новее, без дополнительных библиотек.
Распакуйте архив в одну папку. Запускайте команды в этой папке.

python raspisanie.py                       список всех опубликованных групп
python raspisanie.py --programs            коды и названия направлений
python raspisanie.py --group do/321        сетка, подгруппы и аудитории
python raspisanie.py --group zo/151        занятия заочников по датам
python raspisanie.py --demo                расчёт на условных часах и окнах
python raspisanie.py --template plan.json  создать новый редактируемый план
python raspisanie.py --plan plan.json      рассчитать занятия и остаток окон

Снимок сайта от 20 ноября 2026 г. содержит все 47 групп. Для восьми групп
на момент сбора нет осенних записей: do/142, do/481, do/392, do/393,
do/494, zo/351, zo/451, zo/551. Можно назначать им занятия вручную.
Пустые и весенние сетки видны при просмотре, в осеннюю нагрузку не входят.
Числитель и знаменатель учитываются по календарю осеннего семестра.

В файле teachers.py у каждого преподавателя свой класс. Общий класс
TeacherProfile задаёт базовые окна с понедельника по субботу: вся сетка звонков, до пяти назначений в день.
Воскресенье свободно от занятий. Свой недельный график можно задать в классе
преподавателя полем weekly_available. Замена окон на отдельную дату выглядит так:
    date_overrides = {"2027-02-08": (2, 3, 4), "2027-02-09": ()}
Второй день в этом примере полностью закрыт. Номера 1–8 соответствуют
началу в 08:20, 10:00, 12:05, 13:50, 15:35, 17:20, 18:45 и 20:10.
В semester.json задайте даты семестра start и end. В поле courses каждого класса
оставьте предметы нового семестра, удалите завершённые, добавьте новые.
Задайте hours в академических часах, кратных двум. Для общей лекции укажите
список groups всех групп потока в одной записи. Для раздельных практик создайте
отдельные записи. Планировщик резервирует всю группу на время её практики.
Заметка note сохраняет подгруппу и иные уточнения источника.

Можно назначить занятие всем группам одного направления, курса и формы.
Вместо groups укажите, например, "program": "09.03.04", "year": 2, "form": "do".
Проверьте справочник group_programs в плане: для бакалавриата и специалитета
предложена привязка по серии номера группы. Для магистратуры и аспирантуры
укажите код из --programs по данным деканата или назначайте по номерам групп.

Сетка на сайте описывает уже поставленные занятия. Снимок хранит их отдельно
от часов и подтверждённых окон. В пределах осени 2026 расчёт добавляет занятия
в свободные места с учётом опубликованных сеток групп и преподавателей.
Для другого семестра свободные окна следует вводить с учётом нагрузки на
других факультетах, практик, каникул, экзаменов и иных исключений. Снимок
не обновляется автоматически. Состав потока в заготовке предложен по совпадению
преподавателя, лекции, аудитории, времени и типа недели. Проверьте его по плану.
Однофамильцы с одинаковыми инициалами требуют ручной сверки ФИО.
В модели --demo для каждой записи задана одна пара, окна искусственные.

Корпуса и аудитории описаны отдельными классами в общем файле rooms.py.
Команда python raspisanie.py --rooms 2026-11-25 2 показывает доступность на вторую пару.
В courses можно задать "rooms": ["12 корпус, 304"] с точными названиями из каталога.
Кабинеты выбираются по предмету и виду занятия из снимка расписания этого факультета. Сначала проверяются кабинеты этого преподавателя и его групп.
Команда python raspisanie.py --subject "Теория автоматов" показывает аудитории и группы по предмету. Если место неизвестно, заполните rooms вручную.
Проверьте вместимость и оборудование при выборе допустимых помещений. Дистанционные занятия задаются значением ["Дистанционно"].
Рабочий --plan сохраняет брони в общей базе room_bookings.sqlite3 рядом с rooms.py. Повторный успешный расчёт заменяет брони этого подразделения в пределах дат плана.
Демонстрация --demo читает календарь и не записывает назначения. Для общей базы запускайте программы из одного распакованного дерева СГУ.

Числитель и знаменатель определяются по недельной сетке СГУ. В общем выводе тип указан рядом с датами недели.
У занятия можно задать поле "week" внутри записи courses. Значения: "Ч", "З" или "обе".
Без этого поля тип берётся из опубликованной сетки по предмету, преподавателю и группе.
